Pawly Pet Clinic adalah website sederhana bertema klinik hewan yang dibuat menggunakan Laravel. Website ini memiliki beberapa halaman untuk menampilkan informasi serta daftar hewan.

- Login: Halaman untuk masuk menggunakan username.
- Dashboard: Menampilkan informasi layanan dan dokter Pawly Pet Clinic.
- Profile: Menampilkan username pengguna yang sedang masuk.
- Pengelolaan: Menampilkan daftar jenis hewan menggunakan data array.

- Laravel
- PHP
- Blade Template
- Tailwind CSS
- HTML
